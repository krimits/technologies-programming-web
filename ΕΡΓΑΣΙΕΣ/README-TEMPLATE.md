## Προαπαιτούμενα
- Node.js (≥ 18) + npm
- MongoDB Community Server (τοπικά) ή MongoDB Atlas

## Εκτέλεση
```bash
# 1) server
cd server
npm install
cp .env.example .env      # και συμπλήρωσε MONGO_URI, JWT_SECRET, PORT
npm run seed              # ≥10 προϊόντα, 1 Admin, 1 User
npm run dev

# 2) client (σε άλλο terminal)
cd client
npm install
npm run dev
```
Άνοιξε: http://localhost:5173

- `client/` — React (Vite) + React Router: components/, pages/, api.js, vite.config.js (proxy `/api`)
- `server/` — Express: models/, routes/, middleware/, seed.js, .env.example
