# Πίνακας δοκιμών — Εργασία 2

Οι περιπτώσεις 1–5 είναι αυτές που ζητά η εργασία. Εκτελούνται **αυτόματα** από τα integration
tests (`server/tests/api.test.js`, `npm test`) και στο τέλος υπάρχει ο πλήρης κατάλογος με
τα πραγματικά αποτελέσματα (21/21 επιτυχίες).

| # | Σενάριο | Αναμενόμενο | Πραγματικό | Test |

## Πώς εκτελούνται

```bash
cd server
npm test
```

Τα tests σηκώνουν μια **προσωρινή MongoDB στη μνήμη** (`mongodb-memory-server`), δηλαδή
δεν χρειάζεται εγκατεστημένος MongoDB server και δεν αγγίζουν καμία πραγματική βάση.
